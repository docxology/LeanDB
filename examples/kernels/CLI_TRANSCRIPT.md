and C. Dtypes, ops, languages, architectures and licenses are closed
worlds; the SKU world is gpumarket's `Gpu`. `sig` is a JSON TEXT column
with a declared shape (`ColCodec.json`) that the fingerprint covers;
`launch` and `numeric` are inline structures flattened into
`launch_block`/`launch_smemBytes`/`launch_stages` and
`numeric_deterministic`/`numeric_accum` (`schema` shows each column's
`group`; row JSON nests them back; `insert` takes either spelling);

write, checked on read); `binding` is canonical TEXT; `fuses` is an
`EnumSet OpKind` — an INTEGER bitmask with a mask CHECK, shown as names
in row JSON, whose membership pushes as a bit test. Bench numbers are
illustrative.
